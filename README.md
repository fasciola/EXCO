# EXCO GEOVISTA Website

Static responsive corporate website for EXCO GEOVISTA, focused on drone-based surveying for mining operations and geological surveys.

## Build

```bash
npm run build
```

The deployable site is written to `dist/`.

## Local preview

```bash
npm run dev
```

## Contact form

The contact form is intentionally front-end only. Connect `#contactForm` in `site.js` to your preferred email service, CRM, serverless function, or backend before production launch.
